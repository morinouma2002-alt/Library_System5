Javaで開発した図書館貸出管理システム

📖 概要

Javaのオブジェクト指向プログラミングを活用して開発した、コンソール型の図書館貸出管理システムです。

本の貸出・返却・検索に加え、会員の種類による貸出制限、料金計算、会員ランクによる割引、クーポン機能を実装しています。

継承・抽象クラス・オーバーライド・enum・例外処理を活用し、機能ごとにクラスの役割を分担することを意識しました。

💡 開発で工夫した点

① 継承とオーバーライドの活用

Member を親クラスとし、Student と Teacher が継承する構成にしました。

会員ごとの貸出上限やクーポン割引率など、異なる処理を子クラスで実装しています。

② enumとインスタンス変数の役割分担

クーポンの割引率はenumで管理し、使用状態は会員ごとのインスタンス変数で管理しています。

enumに使用状態を持たせると、複数の会員が同じ状態を共有してしまう問題がありました。

そこで、共通の設定情報と会員ごとの状態を分離しました。

③ Javaの値渡しの理解

メソッドの引数に渡したboolean型の値を変更しても、呼び出し元のフィールドは変更されないことを学びました。

そのため、状態を変更する処理をMemberクラスのメソッドとして実装しました。

④ 例外処理による不正な返却の防止

クーポン入力に問題があった場合、LibraryException を発生させます。

呼び出し元で例外を受け取り、処理を中断することで、料金が正しく計算されていない状態で本が返却されることを防いでいます。
